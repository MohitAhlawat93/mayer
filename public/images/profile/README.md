# Anora profile photos

Upload Anora's approved genuine photos into this folder from GitHub.

Recommended filenames:

- hero.jpg — main full-screen cover image
- about.jpg — About section portrait
- gallery-01.jpg
- gallery-02.jpg
- gallery-03.jpg
- gallery-04.jpg
- gallery-05.jpg

After uploading, open content/site-content.ts and replace each temporary Unsplash URL with the matching local path:

- /images/profile/hero.jpg
- /images/profile/about.jpg
- /images/profile/gallery-01.jpg
- /images/profile/gallery-02.jpg
- /images/profile/gallery-03.jpg
- /images/profile/gallery-04.jpg
- /images/profile/gallery-05.jpg

Use high-quality JPG or WebP photos. A portrait/vertical image works best for hero.jpg and about.jpg. Avoid very large raw camera files; export around 1600–2400 px on the long edge for good web performance.
